# ParkSmart

ParkSmart is a Python app that saves where you parked so you can find your car later.

## Planned features

- Save, view, update, or clear a parking spot.
- Record the garage or lot, level, row or section, and an optional note.
- Save the spot in a JSON file so it stays available after closing the app.
- Show how long the car has been parked.
